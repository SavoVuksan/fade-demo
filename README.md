# Fade Demo
This demo should demonstrate the FADE Method described in [following paper](https://arxiv.org/pdf/2502.16994)

# Development Setup
The app uses angular and thus requires `node.js` on your machine.
To start the app first install the dependencies
```bash
npm i 
```

Start the development server
```bash
npm start
```

Open the app in your [browser](http://localhost:4200)

# Devcontainer Setup
This project also contains a dev container setup this way you don't need to install the dependencies that are required for this project directly on your machine. You use a docker container to work in. To start this project in a devcontainer first make sure to have docker installed on your machine. And to have followed all the steps in [the installation section](https://code.visualstudio.com/docs/devcontainers/containers#_installation)

To start this project in a dev container just open the Command Pallette (`SHIFT + CMD + P`) and search for `Devcontainer: Reopen in Container`. This will open the workspace in a dev container. Now you can work on the project just as regular with the only difference that it is all in a dev container and not on your local machine.
